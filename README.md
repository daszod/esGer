# Spanisch Basics

Lernseite für Spanisch-Anfänger (Deutsch ↔ Spanisch): Alltagssätze, Grundwörter und ein Quiz-Modus.

- `index.html`: Einzeldatei, z. B. für Android (in Chrome öffnen).
- `iphone/`: iPhone-Version als Offline-App.

## iPhone: als Offline-App installieren

1. Einmalig GitHub Pages einschalten: Repo → **Settings** → **Pages** →
   Source „Deploy from a branch“ → Branch `ccr-0f8f1507-fkptpd`, Ordner `/ (root)` → **Save**.
2. Nach 1–2 Minuten in **Safari** öffnen: https://daszod.github.io/esGer/iphone/
3. Teilen-Knopf → **Zum Home-Bildschirm**.
4. App einmal mit Internet öffnen. Danach läuft sie auch offline.

# Spanisch Basics

Lernseite für Spanisch-Anfänger (Deutsch ↔ Spanisch): Alltagssätze, Grundwörter und ein Quiz-Modus.
Läuft auf iPhone und Android als Offline-App.

## Einrichten (einmalig)

GitHub Pages einschalten: Repo → **Settings** → **Pages** →
Source „Deploy from a branch“ → Branch `ccr-0f8f1507-fkptpd`, Ordner `/ (root)` → **Save**.

Adresse danach: https://daszod.github.io/esGer/

## Als App installieren

- **iPhone:** In **Safari** öffnen → Teilen-Knopf → **Zum Home-Bildschirm**.
- **Android:** In **Chrome** öffnen → Menü (⋮) → **App installieren** bzw. **Zum Startbildschirm hinzufügen**.

Die App einmal mit Internet öffnen, danach läuft sie auch offline.

## Änderungen

Nach Änderungen an der App in `sw.js` die Versionsnummer (`spanisch-v2`) erhöhen,
damit installierte Apps die neue Version laden.
